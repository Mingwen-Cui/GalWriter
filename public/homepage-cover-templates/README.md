# 首页与 PPT 封面模板素材

这四套模板使用完全相同的素材结构；网页首页和 PPT 封面都会从同一套图层读取。

每个模板文件夹都包含：

- `preview/preview.png`：模板卡片缩略图，建议 16:9，1920×1080。
- `layers/01-background.png`：完整背景底图，不含文字、按钮、Logo 或水印。
- `layers/02-character.png`：透明人物前景；没有人物时保留空文件夹即可。
- `layers/03-decoration.png`：透明的框线、花瓣、光效、UI 装饰等。
- `layers/04-foreground.png`：透明前景遮罩、桌面、雾气等（可选）。

数字决定默认叠放顺序，数字越大越靠前。不要把标题、菜单文字或可点击按钮烘焙进图片：它们会由网页/PPT 的真实可编辑文字和按钮叠加，以便替换内容、改语言并保留功能。

四个模板都必须遵守同样的 16:9 画布、安全区和图层命名。网页端会保留“继续 / 新游戏 / 存档 / 设置”等真实动作；PPT 端会保留同款视觉，但按钮作为可编辑视觉元素或可选链接导出。

现有 `public/web-homepage/page1` 至 `page4` 的文件暂不移动。完成素材确认后，把相应图片复制或移动到下面对应模板的 `layers/` 和 `preview/` 路径即可。

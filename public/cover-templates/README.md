# 封面模板素材

每个模板一个文件夹，例如 `cover1`、`cover2`、`cover3`、`cover4`。把组成模板的 PNG、JPG、JPEG 或 WebP 图片直接放入该模板文件夹；一个文件夹可放 10 张透明图层图片。已有素材统一使用 `coverN-layer-01.png` 这类命名；若手动改名，必须同步改动同文件夹 `template.json` 内的 `imageUrl`。

在桌面端打开“封面编辑”后，底部会显示对应模板。点击模板会把其中的图片按顺序载入为图层；在画布中调整图片、裁切和添加文字后，点击顶部“保存副本”即可。`cover1`、`cover2`、`cover3`、`cover4` 始终是只读模板，不会被编辑器覆盖。

保存时程序会在 `public/cover-saves/` 下创建一个新的独立文件夹，并写入：

- `template.json`：图层、文字、裁切和画布数据。
- `preview.png`：底部模板卡片的预览图。

这两个文件都由程序维护，不需要手动编辑。原始模板素材图片不会被覆盖。

在线版也会读取构建时生成的模板清单，能够载入这些图片图层并下载合成后的 PNG 封面；在线版不会回写服务器上的 `public` 目录。

# 封面模板素材

每个模板一个文件夹，例如 `cover1`、`cover2`、`cover3`、`cover4`。把组成模板的 PNG、JPG、JPEG 或 WebP 图片直接放入该模板文件夹；一个文件夹可放 10 张透明图层图片。

在桌面端打开“封面编辑”后，底部会显示对应模板。点击模板会把其中的图片按顺序载入为图层；在画布中调整图片、裁切和添加文字后，点击顶部“保存到 cover1”即可。

保存时程序自动写入：

- `template.json`：图层、文字、裁切和画布数据。
- `preview.png`：底部模板卡片的预览图。

这两个文件都由程序维护，不需要手动编辑。原始素材图片不会被覆盖。

在线版也会读取构建时生成的模板清单，能够载入这些图片图层并下载合成后的 PNG 封面；在线版不会回写服务器上的 `public` 目录。

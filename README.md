# 旮旯作家 · GalWriter

### 从旮旯的灵感，写到辽阔的世界。

GalWriter 是一款用于创作视觉小说、分支故事与互动演示的 AI 工作台：在故事画布上组织剧情、人物和场景，预演分支，再导出 Web、视频、PPT 或游戏项目。

## MCP

Windows 桌面版支持 MCP，可通过 Codex 读取、创建和编辑当前项目。在 Assistant →「AI MCP」复制连接指令；本机地址为 `http://127.0.0.1:38941/mcp`，连接时需保持 GalWriter 运行。网站版不能访问访客电脑上的 MCP 服务。

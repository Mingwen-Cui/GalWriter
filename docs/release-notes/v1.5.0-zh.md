# 旮旯作家 · GalWriter v1.5.0

**[English](v1.5.0-en.md) | [日本語](v1.5.0-ja.md)**

GalWriter 1.5.0 汇总了 v1.3.0 之后持续完善的创作、演示与交付能力，让故事从画布编排、AI 协作到多格式导出更连贯。

## 本次更新

- **创作与 AI 协作**：完善故事画布、Assistant 与 Agent 的卡片生成、上下文引用、规划和修订流程。Windows 桌面版内置 MCP 服务，可让 Codex 读取并编辑当前项目。
- **演出与预演**：持续改进剧情动画、角色入退场、场景切换和 Playtest，便于在交付前检查完整故事路径。
- **多格式交付**：完善 Web、视频、PowerPoint 和代码导出工作台；PPT 可嵌入自定义字体，素材检查也覆盖多个导出目标。
- **界面与稳定性**：修复多处语言、交互和导出问题，继续统一编辑与预览体验。
- **完整 / 极简发行包**：提供内置资源较全的 Full 完整包，以及体积更小、按需在线获取预设资源的 Lite 极简包。

## 下载建议

**推荐大多数用户下载 Lite 极简包。**它的安装文件更小，预设图片、音乐与模板按需从官网获取，因此下载或使用这些资源时需要联网。若需要离线使用完整内置资源，请下载 Full 完整包。两个发行版提供相同的应用功能。

Release 附件提供 Windows 安装包与 MSI，以及 Android APK；文件名中的 `full` 表示完整包，`lite` 表示极简包。此版本不附 Web 包、AAB 或 Windows 便携 ZIP。Android 两种 APK 使用相同应用标识，不适合同时安装。

## 升级说明

升级前建议先导出项目 ZIP 备份。项目数据与 AI 配置保存在本机；API Profile 和密钥默认不会随项目 ZIP 导出。

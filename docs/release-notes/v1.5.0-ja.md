# GalWriter v1.5.0

**[中文](v1.5.0-zh.md) | [English](v1.5.0-en.md)**

GalWriter 1.5.0 では、v1.3.0 以降に進めてきた制作、演出、配布機能の改善をまとめ、ストーリーの構成から AI との共同作業、複数形式での書き出しまでをよりスムーズにつなげました。

## 主な更新

- **制作と AI 連携**：ストーリーキャンバス、Assistant と Agent によるカード生成、コンテキスト参照、計画、修正の流れを改善しました。Windows デスクトップ版には MCP サーバーが含まれ、Codex から現在のプロジェクトを読み書きできます。
- **演出とプレイテスト**：ストーリーアニメーション、キャラクターの登場・退場、シーン切り替え、Playtest を継続的に改善しました。
- **複数形式での配布**：Web、動画、PowerPoint、コードの書き出しワークスペースを改善しました。PowerPoint ではカスタムフォントを埋め込めます。素材チェックは複数の書き出し先に対応します。
- **UI と安定性**：言語表示、操作、書き出しに関する問題を修正し、編集とプレビューの一貫性を高めました。
- **Full / Lite 版**：リソースを多く内蔵する Full 版と、必要なプリセットをオンライン取得する軽量な Lite 版を用意しました。

## おすすめのダウンロード

**ほとんどの方には Lite（軽量版）をおすすめします。**インストーラーの容量が小さく、プリセット画像、音楽、テンプレートなどは必要に応じて公式サイトから取得します。これらのリソースをダウンロードするにはインターネット接続が必要です。すべてのリソースをオフラインで使う場合は Full（完全版）を選んでください。アプリの機能は同じです。

Release には Windows インストーラーと MSI、Android APK を掲載します。`full` は完全版、`lite` は軽量版を示します。このリリースには Web パッケージ、AAB、Windows ポータブル ZIP は含まれません。Android の APK は同じアプリ ID を使用するため、2 つを同時にインストールする用途には向きません。

## アップグレード前に

アップグレード前にプロジェクト ZIP をエクスポートしてバックアップしてください。プロジェクトと AI Profile はローカルに保存され、API Profile とキーはデフォルトでプロジェクト ZIP に含まれません。

## 謝辞

制作、プレイテスト、書き出しについてご意見を寄せてくださった皆さまに感謝します。実際のプロジェクトでのフィードバックが多くの改善につながりました。

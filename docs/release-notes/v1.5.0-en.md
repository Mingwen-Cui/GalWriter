# GalWriter v1.5.0

**[中文](v1.5.0-zh.md) | [日本語](v1.5.0-ja.md)**

GalWriter 1.5.0 brings together ongoing improvements since v1.3.0 across authoring, presentation, and delivery, connecting story planning, AI collaboration, and multi-format export more smoothly.

## Highlights

- **Authoring and AI collaboration**: improved the story canvas, Assistant and Agent workflows for card generation, context, planning, and revision. The Windows desktop app includes an MCP server for Codex to read and edit the current project.
- **Presentation and playtesting**: continued work on story animation, character entrances and exits, scene transitions, and Playtest so you can review story paths before delivery.
- **Multi-format delivery**: improved the Web, video, PowerPoint, and code export workspaces. PowerPoint can embed custom fonts, and asset checks cover multiple export targets.
- **Interface and reliability**: fixes for language, interaction, and export issues, with a more consistent editing and preview experience.
- **Full and Lite editions**: choose a Full package with more bundled resources or a smaller Lite package that fetches preset resources on demand.

## Which package should I download?

**We recommend Lite for most users.** Its installer is smaller, and preset images, music, and templates are fetched from the official website when needed. An internet connection is needed to download these resources. Choose Full if you need all bundled resources available offline. Both editions have the same app features.

Release assets are named by platform and edition, including `windows-x64`, `android`, and deployable `web` packages. `full` identifies the complete edition and `lite` the minimal edition. Windows installer, MSI, and portable ZIP packages are provided for both editions. The two Android APKs use the same app identifier and are not intended to be installed side by side.

## Before upgrading

Export a project ZIP backup before upgrading. Projects and AI profiles are stored locally; API profiles and keys are excluded from project ZIPs by default.

## Thanks

Thanks to everyone who shared feedback on authoring, playtesting, and export workflows. Many of these improvements came from using GalWriter in real projects.

# 四套封面的配套 UI 图片提示词

保留现有主界面素材。以下是新增的对话、设置和存档素材，不覆盖已有 `assets/background.png` 或封面效果图。

## 生成与导入规则

- 对话框、姓名牌、选项、设置面板、存档卡片：PNG、真实透明背景，不把棋盘格画进图片；只生成底板和装饰。
- 对话场景：不透明 PNG。每次单独生成一张，不生成拼图或整套 UI 展示图。
- 汉字、人物姓名、正文、按钮文字、存档日期和交互控件由软件绘制；图片里不出现文字、伪文字、水印。
- 优先生成 dialogue-panel.png、choice-button.png 和 dialogue-scene.png。
- 保存后在对应模板的界面中，把文件加入“填充 → 添加 → 图片”；可在上层叠加低透明度纯色或渐变改善可读性。图片不会因仅放入目录而自动替换现有设计。
- 代码导出皮肤会合成为 PNG；网页保留视频填充，PPT/原生游戏皮肤中的视频目前采用首帧。
